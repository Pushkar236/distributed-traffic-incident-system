Fault Tolerance

Simulated failure: node refuses every RPC with UNAVAILABLE
Fail
Recover
What happens
  1. Heartbeat to the failed node times out → marked OFFLINE, NODE_FAILED published.
  2. A new incident for that region is redirected to the nearest online node.
  3. Peers that query it directly get UNAVAILABLE and try the next peer.
  4. Broadcasts it missed are queued and delivered on NODE_RECOVERED.

Open this dashboard in a second browser tab. Click Connect Peer in one tab: it becomes the Traffic Control Center, the other tab answers as the Emergency Response Team. Once the data channel opens, messages travel directly between the two browsers — the server only relays the offer/answer/ICE signalling. This demonstrates real-time peer-to-peer multimedia communication (distributed multimedia system).

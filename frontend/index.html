Fault Tolerance

Simulated failure: node refuses every RPC with UNAVAILABLE
Fail
Recover
What happens
  1. Heartbeat to the failed node times out → marked OFFLINE, NODE_FAILED published.
  2. A new incident for that region is redirected to the nearest online node.
  3. Peers that query it directly get UNAVAILABLE and try the next peer.
  4. Broadcasts it missed are queued and delivered on NODE_RECOVERED.

Beacons give decentralised liveness monitoring (a suspected leader triggers a Bully election) and clock-offset estimates. RBS compares two receivers' arrival times of the same beacon, so the sender's clock and send delay cancel out. Try Fail Mumbai Node above and watch the status change.
